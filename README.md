# 我的第一張地圖

一個為 3–6 歲兒童設計的北角社區探索地圖。介面以大圖案、繁體中文和粵語朗讀，幫助小朋友在無壓力的探索中認識家附近的常見場所。

## 功能

- 北角附近約 1 公里、縮放級別 15–19 的安全地圖範圍
- 21 種社區場景；每類最多顯示 5 個經 OpenStreetMap 核對的真實地點
- 大型圖案、繁體字標籤和兒童友善的場所介紹卡
- 使用瀏覽器語音功能朗讀場所名稱和簡介
- 基於 OpenStreetMap 的簡化無標籤底圖
- PWA 離線快取，曾瀏覽的地圖瓦片可再次離線使用
- 支援桌面和手機版面

## 本機開發

```bash
npm install
npm run dev
```

建立正式版本：

```bash
npm run build
```
