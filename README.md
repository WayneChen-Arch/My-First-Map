# 我的第一張地圖

一個為 3–6 歲兒童設計的北角社區探索地圖。介面以大圖案、繁體中文和粵語朗讀，幫助小朋友在無壓力的探索中認識家附近的常見場所。

## 功能

- 北角附近約 4 公里、縮放級別 14–16 的安全地圖範圍
- 20 種精選社區場景，包括學校、超市、醫院、公園及交通設施
- 大型圖案、繁體字標籤和兒童友善的場所介紹卡
- 使用瀏覽器語音功能朗讀場所名稱和簡介
- 基於 OpenStreetMap 的簡化無標籤底圖
- PWA 離線快取，曾瀏覽的地圖瓦片可再次離線使用
- 支援桌面和手機版面

## 本機開發

```bash
npm install
npm run dev
```

建立正式版本：

```bash
npm run build
```
